# IberOSINT

Plataforma OSINT basada en Ubuntu orientada a facilitar la instalación, automatización y visualización de herramientas de inteligencia en fuentes abiertas.

## Objetivos

- Centralizar herramientas OSINT.
- Facilitar su instalación y uso.
- Automatizar procesos de recopilación de información.
- Visualizar resultados desde una interfaz unificada.
- Proporcionar un entorno virtualizado listo para usar.
