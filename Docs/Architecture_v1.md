# Arquitectura IberOSINT v1.0

## Objetivo

Desarrollar una plataforma OSINT basada en Ubuntu 24.04 LTS que facilite la instalación, automatización y visualización de herramientas de inteligencia en fuentes abiertas.

## Componentes principales

### Installer

Sistema encargado de la instalación y configuración automática de herramientas OSINT.

### Launcher

Interfaz principal para el acceso a funcionalidades de la plataforma.

### Core

Conjunto de módulos desarrollados en Python para automatizar tareas OSINT y procesar resultados.

### Dashboard

Sistema de visualización de resultados y consultas.

### Resources

Recursos auxiliares, configuraciones, marcadores y elementos necesarios para la plataforma.

### Docker

Servicios dockerizados para facilitar despliegue y portabilidad.

### Results

Almacenamiento de resultados generados durante las investigaciones.

## Entorno base

- Ubuntu 24.04 LTS Desktop
- VirtualBox
- Python 3
- Docker

## Estado

Versión inicial de arquitectura.
